# Calendar Personalised Platform

A production-ready personalized calendar creation platform.

## Project isolation
This repository is intentionally independent from all Sterling and other existing projects.

## Product flow
1. User signs in.
2. User browses calendar templates.
3. User selects a template.
4. User uploads a doctor/person/product image.
5. The image is composed into the template.
6. A 12-page calendar preview is generated.
7. The calendar can be saved and downloaded as PDF.
8. Admins can manage users, templates, calendars, and generated artwork.

## UI direction
The visual system takes inspiration from La Rotonde's editorial approach: bold typography, strong image-led composition, generous spacing, and purposeful motion. It is an original implementation and does not copy La Rotonde assets or branding.

## Planned stack
- Next.js / React / TypeScript
- Tailwind CSS
- Supabase Auth / PostgreSQL / Storage
- SVG-driven calendar templates
- Server-side image and PDF generation
